01Ringkasan

AimFinder adalah koleksi tool browser untuk mencari sensitivitas mouse optimal di VALORANT, CS2, dan FPS lain lewat uji aim 3D (Three.js + Pointer Lock). Tidak ada build step, tidak ada backend — murni HTML statis.

PSA

chat.html, play.html — binary search klasik, baseline cepat.

Continuous AI

deep/seek/aim/finder/valo — optimasi berjalan terus selama trial.

Lab

rant.html, sens.html — Calibration Lab amber, sens.html sudah contrast-fix (rekomendasi).

Prototype

gpt.html — 255 baris untuk belajar logika AI training.

02Mulai cepat

  1. Buka landing → pilih sens.html dulu jika bingung.
  2. Klik canvas → izinkan Pointer Lock (mouse terkunci untuk input mentah).
  3. Selesaikan sesi: Flick (8 target acak), Tracking (8 detik), Switching (2 target bergantian).
  4. Catat rekomendasi sens + DPI. Uji ulang di Deathmatch / Range in-game.
Hasil browser adalah estimasi awal. Input lag, engine game, dan resolusi crosshair berbeda dengan kondisi in-game. Jadikan titik awal, lalu fine-tune manual.

05Metodologi

PSA binary search (chat/play)

Uji batas atas-bawah sensitivitas, persempit dengan pilihan pengguna per ronde. Cepat, deterministik.

Continuous AI (deep/seek/aim/finder/valo)

Optimasi berjalan tiap trial dari trajectory + angular velocity/acceleration, bukan sekali di akhir.

Flick / Tracking / Switching + skor

Warisan varian awal (index lama): 5 titik sens di sekitar base (0.5×–1.5×), 3 tugas per titik, lalu:

score = (flick*w_flick + tracking*w_tracking + switching*w_switching) × 0.85
        + consistency × 0.15

Bobot playstyle: Duelist (flick), Balanced, Sentinel (tracking).

Tips: kunci DPI dulu (400/800), ubah hanya in-game sens. eDPI = DPI × sens. Samakan eDPI saat pindah varian agar sebanding.

07Browser & teknis

  • Pointer Lock API wajib — klik canvas untuk mengunci mouse. Esc untuk keluar.
  • WebGL + Three.js r128 CDN (cdnjs) — butuh internet saat pertama load kecuali sudah cache.
  • Desktop + mouse disarankan. Touchpad / mobile tidak akurat.
  • Tidak ada backend / cookie / tracking. Semua kalkulasi di tab lokal.
  • Jika embed via iframe, izinkan allow="pointer-lock".

09Deploy Wasmer Edge

  1. Push repo ke GitHub (yuumuu/aimfinder).
  2. App sudah ada: yuumuu/aimfinder → aimfinder.wasmer.app (provider staticfile, static_dir: public, SWS 2.38.0).
  3. Deploy manual via CLI (sudah login sebagai yuumuu):
    wasmer deploy --owner yuumuu --app-name aimfinder --non-interactive
  4. Atau auto-deploy dari dashboard Wasmer → Apps → aimfinder → Redeploy.
  5. Verifikasi: buka /index.html, /docs.html, dan satu varian (/sens.html).
Repo sengaja tanpa wasmer.toml / app.yaml — Shipit (staticfile) men-generate-nya saat build dari Staticfile.

10FAQ

Mana yang paling akurat?
Semua estimasi. Mulai dari sens.html (kontras terbaik), bandingkan dengan finder.html.

chat vs play bedanya apa?
Logika sama (PSA), play lebih embed-friendly.

Butuh install?
Tidak. Buka URL Wasmer langsung.

Bolehkah ubah varian?
Sesuai aturan repo saat ini: jangan. Buat file baru jika eksperimen.

Pointer Lock gagal?
Gunakan Chrome/Edge desktop, HTTPS (Wasmer sudah HTTPS), klik langsung canvas, matikan overlay perekam.
